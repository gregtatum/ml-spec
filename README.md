# ml-spec

The "spec" project is a collection of tests and written specifications that
capture what I learn about a topic. In this repo the topic is machine learning,
and the goal is to turn understanding into code-backed, runnable specs.

Each project keeps its own README describing the spec it is asserting and the
experiments that support it.

## Workspace layout

- `algorithms`: algorithm implementations and specs.
- `feed-forward`: neural network experiments and training notes.
- `text-embedding`: text embedding experiments and notes.
